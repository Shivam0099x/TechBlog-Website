# 📰 TechBlog – Full Stack Blogging Platform

TechBlog is a modern full-stack blogging platform built with **Next.js 16**, **TypeScript**, **PostgreSQL**, and **Prisma ORM**. It enables users to explore technology articles while providing authenticated authors with a powerful dashboard to create, edit, and manage rich-text blog posts.

Designed with performance, scalability, and user experience in mind, the application includes secure authentication, Cloudinary image uploads, SEO-friendly URLs, category & tag organization, and a responsive interface.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/Shivam0099x/TechBlog-Website.git
```

## Move into Project

```bash
cd TechBlog-Website
```

## Install Dependencies

```bash
npm install
```

## Configure Environment Variables

Create a `.env` file.

```env
DATABASE_URL=

BETTER_AUTH_SECRET=
BETTER_AUTH_URL=

CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
```

Generate Prisma Client

```bash
npx prisma generate
```

Run Database Migration

```bash
npx prisma migrate dev
```

Start Development Server

```bash
npm run dev
```
